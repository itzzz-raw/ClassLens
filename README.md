# CLASSLENS: Class Record Management System

ClassLens is an AI-driven Class Record Management System with integrated Program Outcome Validation using eXtreme Gradient Boosting (XGBoost). Built specifically for the College of Computer Studies (CCS) at Camarines Sur Polytechnic Colleges (CSPC), this platform transforms static classroom records into actionable, predictive pedagogical insights.

## 📖 Project Overview
Higher education institutions often struggle with manual, retroactive class record management. ClassLens addresses this by processing traditional `.xlsx` and `.csv` class records to automate two critical functions:
1.  **Program Outcome (PO) Validation:** Automates the mapping of student assessment scores to the specific Course Outcomes (COs) and competency benchmarks of the 2019, 2022, and 2023 computing curricula (BSCS, BSIT, BSIS) under PICAB standards[cite: 1].
2.  **Early Academic Risk Detection:** Utilizes an embedded XGBoost machine learning model to calculate academic risk probabilities (Attained, At-Risk, High-Risk) within a critical four-week "Early Risk Window," allowing for proactive student intervention[cite: 1].

## ✨ Key Features
*   **Automated Data Ingestion:** Parses raw faculty spreadsheets and strictly enforces digital anonymization (hashing) to comply with the Data Privacy Act of 2012 (RA 10173)[cite: 1].
*   **Behavioral Metric Extraction:** Calculates non-intrusive, file-derived behavioral signals, specifically *Submission Velocity (SV)* and *Iterative Data Update Behavior (IDUB)*[cite: 1].
*   **Predictive Dashboard:** Provides instructors with color-coded, user-friendly administrative dashboards to track risk labels generated by the XGBoost engine[cite: 1].
*   **Curriculum Compliance Reporting:** Generates structured continuous quality improvement reports (Met, Partially Met, Not Met)[cite: 1].
